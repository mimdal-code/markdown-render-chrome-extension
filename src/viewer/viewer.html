Keyboard shortcuts & help

Navigation

jScroll to the next heading
kScroll to the previous heading
g gScroll to top (press g twice quickly)
GScroll to bottom
[Toggle the sidebar
Ctrl + BToggle the sidebar

Search

Ctrl + FFocus the search box
EnterJump to the next match
Shift + EnterJump to the previous match
n / NNext / previous match (when search has a query)
EscClear the search and return to normal view

Content

Hover a headingClick the # to copy a permalink
Click a code block's Copy buttonCopy the whole block to the clipboard
Click a task checkboxToggle it — the state is saved per file
Click a TOC entryScroll to that heading

Print

Ctrl + PPrint or save as PDF (chrome UI is hidden automatically)

Notes

This extension runs entirely offline. No network requests, no telemetry, no external fonts. All settings are stored in chrome.storage.sync (synced across your Chrome profiles) and task checkboxes are stored in chrome.storage.local (per machine).
For best results with Persian text, install the Vazirmatn font on your system. For Arabic, install Noto Naskh Arabic or Droid Arabic Naskh. The viewer never downloads fonts — it only uses what's installed on your computer. See Options → Fonts for details.
