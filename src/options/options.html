These settings apply to the viewer on every page. They are stored in chrome.storage.sync.

Fonts come from your computer only.
This extension never downloads fonts. It uses fonts that are already installed on your operating system. If a font name below is not installed, the browser silently falls back to the next name in the list. To use a specific font, install it yourself first.

سلام دنیا — نمونه متن فارسی. שלום עולם — דוגמת טקסט עברית. مرحبا بالعالم.
Comma-separated CSS font-family list. The browser tries each name in order and skips any that isn't installed. Recommended first choice: Vazirmatn (Persian) or Droid Arabic Naskh / Noto Naskh Arabic (Arabic).
If Vazirmatn is not installed, get it from github.com/rastikerdar/vazirmatn/releases. For Arabic Naskh, install Noto Naskh Arabic via your OS package manager or from Google Noto.
